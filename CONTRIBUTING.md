# Contributing to Plamenu

Use [Codefloe](https://codefloe.com/plamenu/plamenu) for issues and pull requests.
Report vulnerabilities privately through [SECURITY.md](SECURITY.md).

Discuss large features, schema or federation changes, and new dependencies
before implementing them. Small fixes can go directly to a pull request.

- Explain the problem, resulting behavior, and validation.
- Add regression coverage for behavior changes.
- Update documentation and the `Unreleased` changelog when appropriate.
- Call out schema, configuration, security, federation, and performance effects.
- Sign commits and add the DCO sign-off with `git commit -S -s`.

The [development guide](docs/DEVELOPMENT.md) contains setup commands and required
checks. [Documentation guidance](docs/contributing/index.md#documentation)
covers factual claims, examples, and the docs build.
