# Using Plamenu

Open your server's HTTPS website. Register if registration is enabled, or use
an invitation or account supplied by its administrators. Complete any email
confirmation or approval requested on screen, then sign in.

Set your display name, biography, avatar, language and time zone in **Settings**.
Your handle identifies your account across servers. To follow someone elsewhere,
search for their full `@name@server.example` handle or public profile URL.

| Task | Where to go |
| --- | --- |
| Read accounts you follow | Home; Lists for selected followed accounts |
| Browse local and federated public posts | Live feeds |
| Find people, communities, posts and videos | [Search and Discover](discovery.md) |
| Write, reply, quote, schedule or edit | [Posting](posting.md) |
| Join discussions or organize an event | [Groups and events](groups-and-events.md) |
| Listen, upload, share or organize audio | [Music](music.md) |
| Watch, publish or broadcast | [Video](video.md), [live broadcasting](live.md) |
| Run an app with other people | [Apps and Webxdc](apps.md) |
| Review activity and control delivery | [Notifications](notifications.md) |
| Change privacy, security, filters or export data | [Account and safety](account-and-safety.md) |

Post and profile menus provide follow, reply, quote, boost, favourite, bookmark,
mute, block and report actions where permitted. Bookmarks keep posts for you;
favourites also send a social interaction to the author. Private mentions are
messages addressed to accounts; they are **not end-to-end encrypted**.

Many pages work with ordinary links and forms when JavaScript is disabled.
Enhanced players, browser broadcasting, live updates and interactive Webxdc
apps need scripts. Keyboard and media alternatives are described in
[accessibility](accessibility.md).

You can also use a [Mastodon-compatible client](../api/index.md). A client may
expose fewer features than the website. Use the hosting domain for sign-in even
if your handle uses a different domain.
